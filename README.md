# Armstrong Number in C

This program checks whether a given three-digit number is an Armstrong number.

## File

armstrong_number.c

## Concepts Used

- while loop
- if-else
- Modulus operator
- Control flow

## How to Run

gcc armstrong_number.c -o armstrong_number
./armstrong_number

## Sample Output

Enter a number: 153
153 is an Armstrong number
